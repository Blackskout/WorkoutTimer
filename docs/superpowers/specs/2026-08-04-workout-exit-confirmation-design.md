# Подтверждение выхода и завершения тренировки

**Дата:** 2026-08-04
**Ветка:** `feat/workout-exit-confirmation`

## Проблема

На экране `WorkoutExecution` два действия необратимы и происходят по одному касанию:

1. **Выход с экрана.** Стрелка «Назад» в `TopAppBar` вызывает `onExerciseCompleted()` — навигацию назад. Сессия при этом **не сохраняется**: запись в БД происходит только в `moveToNextExercise()`, когда дожат последний подход последнего упражнения. То есть случайное касание стирает всю тренировку.

2. **Завершение тренировки.** Кнопка «Закончить упражнение» на последнем подходе последнего упражнения молча закрывает тренировку и пишет сессию в историю. Пользователь не отличает её от обычного перехода к отдыху.

Дополнительно: системная кнопка/жест «Назад» экраном не перехватывается вообще, поэтому уводит с экрана мимо любого диалога.

## Решение

Два диалога подтверждения. Логика выполнения тренировки не меняется — подтверждение вставляется **перед** существующими вызовами.

### Где живёт состояние диалогов

Во Compose, через `remember { mutableStateOf(false) }` — так же, как уже сделано с `showNoteDialog` в этом же файле.

Рассмотренная альтернатива — держать флаги во `WorkoutExecutionViewModel`. Отвергнута: видимость диалога — чистое UI-состояние, во ViewModel оно размывает её ответственность и заводит в файле второй способ делать то же самое. Плата за выбор — диалог закрывается при повороте экрана; это безвредно, пользователь нажимает кнопку ещё раз.

### 1. Признак «последний подход тренировки»

Правило «этот подход завершает тренировку» относится к устройству тренировки, а не к вёрстке, поэтому живёт во ViewModel:

```kotlin
val isLastSetOfWorkout: Boolean
    get() = (_uiState.value as? WorkoutExecutionState.Active)
        ?.let { it.currentSet == it.totalSets && exerciseIndex == exercises.lastIndex } == true
```

Возвращает `false` в любом состоянии, кроме `Active`.

### 2. Диалог завершения тренировки

- Нажатие «Закончить упражнение» при `isLastSetOfWorkout == true` → показать диалог вместо вызова `onExerciseFinished()`.
- Подтверждение → `viewModel.onExerciseFinished()`. Дальше всё как сейчас: сессия пишется в БД, состояние становится `Finished`, всплывает существующий диалог «Тренировка завершена».
- Отмена → диалог закрывается, состояние не тронуто.
- При `isLastSetOfWorkout == false` кнопка работает как раньше, без диалога.

Текст: заголовок «Завершить тренировку?», тело «Это последний подход. Тренировка будет завершена и сохранена в историю.», кнопки «Завершить» / «Отмена».

### 3. Диалог выхода

Один диалог на два источника — стрелка в `TopAppBar` и системный «Назад» (`BackHandler`).

Оба источника показывают диалог **только** когда `uiState` — это `Active` или `Rest`. В `Loading`, `Error` и `Finished` терять нечего (в `Finished` сессия уже сохранена), там выход происходит сразу, без вопросов. Без этого условия приложение спрашивало бы «прогресс не сохранится» уже после того, как прогресс сохранён.

- Подтверждение → `onExerciseCompleted()` (существующий колбэк навигации).
- Отмена → диалог закрывается.

Текст: заголовок «Выйти из тренировки?», тело «Прогресс не будет сохранён.», кнопки «Выйти» / «Отмена».

### 4. Таймер во время диалога

Таймер отдыха продолжает тикать под диалогом и не ставится на паузу. Пользователь ещё не вышел; если он нажмёт «Отмена», таймер не должен оказаться сбитым.

## Что НЕ входит

- Кнопка «Сохранить и выйти» / сохранение частичной сессии. Это отдельная фича: требует решить, что «недоделанная тренировка» значит в статистике.
- Отдельная кнопка «Завершить тренировку досрочно».
- Пауза таймера на время диалога.

## Тесты

Unit-тест на `isLastSetOfWorkout` в `WorkoutExecutionViewModelTest`:

- `false` в середине тренировки (не последний подход и/или не последнее упражнение);
- `true` на последнем подходе последнего упражнения.

Сами диалоги — Compose UI; в проекте нет Robolectric, юнит-тестами не покрываются. Проверяются вручную.

- `presentation/screen/workoutExecution/WorkoutExecutionScreen.kt` — `BackHandler`, два диалога, условия показа.
- `test/.../WorkoutExecutionViewModelTest.kt` — тесты на `isLastSetOfWorkout`.
